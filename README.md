### 🚀 Featured Engineering Projects

#### 1. [🎬 Movie Recommendation System](https://github.com/dhruvsingh29-Driod/movie-recommendation-system)
> **Hybrid ML Recommendation Engine (Python 3.11, Scikit-learn, Streamlit, MovieLens 100K)**
- Engineered content-based TF-IDF vectorization and item-item collaborative filtering over 100K ratings and 9.7K movies.
- Deployed on **Streamlit Community Cloud** with sub-10ms query latency, interactive trailers, and explainability reasoning.
- Benchmarked offline Information Retrieval metrics (**Precision@5: 1.000**, **MRR: 1.000**) and built a headless REST API microservice.
- 🔗 **Live Demo:** [dhruvsingh-movies.streamlit.app](https://dhruvsingh-movies.streamlit.app/)

#### 2. [🎓 Campus Placement Management System](https://github.com/dhruvsingh29-Driod/campus-placement-management-system)
> **Full-Stack Recruitment Management Platform (Node.js, Express.js, REST API, Vanilla UI)**
- Automated server-side eligibility verification engine enforcing CGPA cutoffs and branch constraints.
- Multi-stage recruitment workflow tracker (`Applied` ➔ `Shortlisted` ➔ `Interview` ➔ `Selected` / `Rejected`).
- Executive placement KPI analytics, salary insights, CSV report generator, and interactive OpenAPI 3.0 Swagger docs.
- 9/9 automated unit & integration tests running with native test runner.

#### 3. [🏢 Enterprise Placement Management Backend API](https://github.com/dhruvsingh29-Driod/placement-management-spring-boot)
> **Production Spring Boot REST Microservice (Java 21 LTS, Spring Boot 3, Spring Data JPA, Hibernate)**
- Layered enterprise architecture adhering to Controller-Service-Repository separation of concerns.
- Dual database profiles (zero-setup in-memory H2 database + enterprise MySQL 8.0) and Docker containerization.
- Interactive OpenAPI 3 / Swagger UI (`/swagger-ui/index.html`) with Mockito and Spring Boot integration tests.
